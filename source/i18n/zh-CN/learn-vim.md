# Vim

## **移动**

**hjkl** 是 Vim 中最核心、最基础的移动方式。它们让你可以在各个方向上逐格移动光标。

![在 Vim 中用 hjkl 移动](https://www.barbarianmeetscoding.com/images/vim-basics-hjkl.jpg)

## **模式切换**

使用 **ESC / 'Ctrl-[' / 'Ctrl-Z'** 和 **i/a** 在 **普通模式** 和 **插入模式** 之间切换。

![从普通模式切换到插入模式再切回来](https://www.barbarianmeetscoding.com/images/vim-basics-insert-to-normal.jpg)

## **基本操作**

在 Vim 中，**Ctrl-C** 并不是复制的意思，我们使用 **y（代表 yank）** 来完成复制。

同样，我们使用 **p（代表 paste）** 来完成 **Ctrl-V** 的粘贴工作。

- 使用 **`b`**（**b**ack）向后跳到单词的开头
- 使用 **`e`**（**e**nd）跳到单词的末尾
- 使用 **`ge`** 向后跳到单词的末尾

如果你想按 **WORD**（以空格分隔）来移动，可以使用前面提到动作的大写版本（**`W`**、**`B`**、**`E`**、**`gE`**）。

- 使用 **`f{字符}`**（**f**ind）移动到当前行中某个字符的下一次出现位置。例如，**`f"`** 会让你跳到下一个双引号出现的位置。
- 如果目标在光标后方，可以使用 **`F{字符}`** 来查找某个字符的上一次出现位置
- 使用 **`t{字符}`** 将光标移动到某个字符下一次出现位置的前一格（可以把 `t{字符}` 理解为将光标移动到 un**t**il 该字符的位置）。
- 同样，你可以使用 **`T{字符}`** 实现与 `t{字符}` 相同的效果，但方向相反

使用 **`f{字符}`** 之后，你可以输入 **`;`** 跳到该字符的下一次出现位置，或输入 **`,`** 跳到上一次出现位置。**你可以把 `;` 和 `,` 看作重复上次字符查找的命令**。

- **`0`**：移动到**当前行的第一个字符**
- **`^`**：移动到**当前行的第一个非空白字符**
- **`$`**：移动到**当前行的末尾**
- **`g_`**：移动到**当前行末尾的非空白字符**
- **`}`** 向下跳转整个段落
- **`{`** 类似，但方向**向上**
- **`CTRL-D`** 通过滚动页面向**下移动半页**
- **`CTRL-U`** 同样通过滚动页面向**上移动半页**
- 使用 **`/{模式}`** 在文件中**向前搜索**
- 使用 **`?{模式}`** 进行**向后搜索**

之后你可以按需进行一些编辑，然后用 **`n`** 跳到下一个匹配项（或用 **`N`** 跳到上一个）。**你可以把 `n` 理解为重复一次搜索**。

Vim 热衷于帮你节省时间：随时输入 **`/<Enter>`** 或 **`?<Enter>`** 即可执行上一次搜索（向前或向后）。或者使用 **\*** 搜索光标下的单词（**`#`** 则反向搜索同一单词）。

**计数（count）是数字，用于放大命令的效果**。你可以在任何命令前加上计数，格式如下：

**{计数}{命令}**

例如：

- **`2w`** 让光标向前移动 2 个单词。
- **`5j`** 将光标向下移动 5 行。
- **`3;`** 让你跳到某个字符的第 3 次出现位置。
- **`2/baby`** 让你直接飞到文档中 `baby` 的第 2 次出现位置。

- 使用 **`gd`** 跳到光标下内容的定义处。
- 使用 **`gf`** 跳到 import 语句中的文件。
- 输入 **`gg`** 跳到文件顶部。
- 使用 **`{行号}gg`** 跳到指定行。
- 使用 **`G`** 跳到文件末尾。
- 输入 **`%`** 跳到匹配的 **`({[]})`**。

## **运算符系列**

将运算符和动作组合使用时，遵循以下任一模式：

- {运算符}{计数}{动作}
- {计数}{运算符}{动作}

![Vim 运算符](https://www.barbarianmeetscoding.com/images/vim-operators.jpg)

- **运算符**决定了你想执行什么操作：删除、修改、复制（yank）、格式化等。
- **计数**让你通过重复执行动作 *count* 次来放大运算符的效果。
- **动作**表示运算符所作用的文本范围。

例如，`d2w` 组合可以让你**删除两个单词**。

![运算符示例 d2w 删除两个单词](https://www.barbarianmeetscoding.com/images/vim-operators-d2w.jpg)

- 使用 **`d5j`** 向下删除 5 行
- 输入 **`df'`** 删除当前行中从光标到 **`'`** 字符第一次出现位置之间的所有内容（包括该字符本身）
- 或者输入 **`dt'`** 实现与上面类似的效果，但不包含该字符（即删除到 **`'`** 字符之前）
- 使用 **`d/hello`** 删除直到 **`hello`** 第一次出现位置的所有内容
- 输入 **`ggdG`** 删除整个文档

## **常用运算符**

![一些常用的 Vim 运算符](https://www.barbarianmeetscoding.com/images/vim-operators-commands.jpg)

- **`c`**（**c**hange）：修改会先删除一段文本，然后进入*插入模式*，让你继续输入，把原文替换成其他内容。修改运算符就像把 **`d`** 和 **`i`** 命令合二为一。这种双重性使它成为最实用的运算符
- **`y`**（**y**ank）：Vim 术语中的复制
- **`p`**（**p**ut）：Vim 术语中的粘贴
- **`g~`**（切换大小写）：在大小写之间切换字母。也可以使用 **`gu`** 转为小写、**`gU`** 转为大写
- **`>`**（右移）：增加缩进
- **`<`**（左移）：减少缩进
- **`=`**（格式化代码）：格式化代码
- **将运算符重复一次可使其作用于整行**：**`dd`** 删除整行，**`cc`** 修改整行，等等。
- **将运算符大写可让其执行更强（或替代）的默认行为**：**`D`** 删除从光标到行尾的内容，**`C`** 修改到行尾，**`Y`** 像 **`yy`** 一样复制整行，**`P`** 在光标前粘贴内容，等等。

## **文本对象**

在命令中指定文本对象的方式是：将字母 **`a`**（**a** 文本对象加空白）或 **`i`**（**inner** 内部对象，不含空白）与代表文本对象本身的字符组合：

![Vim 文本对象](https://www.barbarianmeetscoding.com/images/vim-text-objects.jpg)

内置文本对象包括：

![Vim 文本对象命令](https://www.barbarianmeetscoding.com/images/vim-text-objects-commands.jpg)

- **`w`** 代表**单词**（**w**ord）
- **`s`** 代表**句子**（**s**entence）
- **`'`**、**`"`**、**```** 代表引号
- **`p`** 代表**段落**（**p**aragraph）
- **`b`**（或 **`(`**、**`)`**）代表由 **`()`** 包围的块
- **`B`**（或 **`{`**、**`}`**）代表由 **`{}`** 包围的块
- **`<`**、**`>`** 代表由 **`<>`** 包围的块
- **`[`**、**`]`** 代表由 **`[]`** 包围的块
- **`t`** 代表标签（tag）。

因此，要删除不同的文本片段，你可以使用以下任意命令：

- **`daw`** **d**elete **a** **w**ord（**删除**一个**单词**，包含其后的空白）
- **`ciw`** **c**hange **i**nner **w**ord（**修改**一个**单词的内部**）
- **`das`** **d**elete **a** **s**entence（**删除**一个**句子**，**`dis`** 则删除句子内部）
- **`da"`** 删除双引号内的内容，包括引号本身（**`di"`** 只删除引号**内**的内容，保留引号）
- **`ci"`** 修改双引号内的内容
- **`dap`** 删除一个段落
- **`dab`**、**`da(`** 或 **`da)`** 删除由 **`(`** 包围的块
- **`daB`**、**`da{`** 或 **`da}`** 删除由 **`{`** 包围的块
- **`dat`** 删除一个 HTML 标签
- **`cit`** 修改一个 HTML 标签的内容

**将文本对象与运算符组合使用极为强大**，你会发现自己经常依赖它们。像 `cit`、`ci"` 和 `cib` 这样的组合简直太棒了。

**`.` 命令可以重复你上一次所做的修改**。

- **`x`** 等价于 **`dl`**，删除光标下的字符
- **`X`** 等价于 **`dh`**，删除光标前的字符
- **`s`** 等价于 **`ch`**，删除光标下的字符并进入*插入模式*
- **`~`** 切换单个字符的大小写

- 输入 **`u`** 撤销上一次修改，
- 输入 **`CTRL-R`** 重做，

## **插入模式**

- **`i`** 代表**i**nsert（插入），
- **`a`** 代表**a**ppend（追加）。
- **`I`** 让你在当前行的开头进入*插入模式*，
- **`A`** 让你在当前行的末尾进入*插入模式*。

![插入模式命令](https://www.barbarianmeetscoding.com/images/vim-insert-mode.jpg)

1. **`o`** 在当前行下方插入一个新行并进入插入模式（助记：**o**pen a line below，在下方打开一行）
2. **`O`** 在当前行上方插入一个新行并进入插入模式
3. **`gi`** 让你在上次做修改的位置进入*插入模式*。如果你不小心退出了*插入模式*，想回到原来的位置继续输入，这个命令非常好用。（此行为与 Vim 略有不同，在 Vim 中 `gi` 会把你送到上次离开*插入模式*的地方）。

![更多插入模式命令](https://www.barbarianmeetscoding.com/images/vim-more-insert-mode.jpg)

- **`CTRL-h`** 让你删除**最后输入的一个字符**
- **`CTRL-w`** 让你删除**最后输入的一个单词**
- **`CTRL-u`** 让你删除**最后输入的一行**

## **选择文本与可视模式**

**可视模式相当于 Vim 中用鼠标选择文本的方式**。

![可视模式命令](https://www.barbarianmeetscoding.com/images/vim-visual-mode-commands.jpg)

- **`v`** 进入**按字符**的可视模式。此模式让你逐字符地选择文本
- **`V`** 进入**按行**的可视模式。此模式让你逐行地选择文本
- **`<C-V>`** 进入**按块**的可视模式。此模式让你用矩形块来选择文本

## **对搜索进行操作**

**`gn`** 的工作方式如下：

1. 如果你位于某个搜索匹配项上，它会在*可视模式*下选中该匹配项。
2. 如果你处于*可视模式*，它会将当前选区扩展到下一个匹配项的末尾。
3. （也是最棒的部分）如果你处于*运算符等待模式*，**它会对下一个匹配项进行操作**。

这到底意味着什么？**这意味着利用 `gn`，我们只需一次按键就能对下一个匹配项进行操作**。有了 **`gn`**，**`.`** 命令就涵盖了**“将这个修改应用到下一个匹配项”**的含义。

## **复制与粘贴**

![Vim 复制粘贴命令](https://www.barbarianmeetscoding.com/images/vim-copy-paste-commands.jpg)

### **yank（复制）**

**`y`** 是一个运算符。你可以把它与你学过的任何动作和文本对象组合使用，随心所欲地复制内容：

- **`yl`** **y**anks a **l**etter（复制一个字母），
- **`yaw`** **y**anks a **w**ord（复制一个单词），
- **`yas`** **y**anks a **s**entence（复制一个句子）
- **`yi(`** **y**anks everything within **`(`**（复制 **`(`** 内的所有内容），以此类推……

如果你把 **`y`** 重复一次写成 **`yy`**，你就得到了一个**按行的运算符**，就像 **`dd`** 和 **`cc`** 那样，用来复制整行。**`Y`** 命令也会复制整行。我更喜欢用 **`yy`**，但你可以随意选择。

### **paste（粘贴）**

要粘贴内容，使用 **`p`** 命令及其变体：

- **`p`** 在光标之后粘贴内容
- **`P`** 在光标之前粘贴内容
- **`gp`** 与 **`p`** 相同，但把光标放在粘贴内容之后
- **`gP`** 与 **`P`** 相同，并把光标放在粘贴内容之后

这粘贴的灵活性真是令人惊叹。

在 Vim 中粘贴有点特殊，**`p`** 和 **`P`** 的行为取决于你复制的是字符还是行。如果你复制的是**字符**，粘贴会把那些字符放在光标之后或之前（这没什么意外）。但如果你复制的是**行**，粘贴会把这些行放在光标所在行之后或之前。

![Vim 实用的复制粘贴](https://www.barbarianmeetscoding.com/images/vim-useful-copy-pasting.jpg)

### **寄存器**

*你还记得大约十分钟前提到的 `d` 和 `c` 吗？* 嗯，当我说它们把文本删除到虚无时，**我撒谎了！** 它们实际上是**剪切**了内容。

寄存器就像一个特殊的剪贴板，可以同时保存多项内容。以下寄存器非常实用：

- **无名寄存器** **`"`** 是你在没有明确指定寄存器时复制和剪切内容所存放的地方。可以说是默认寄存器。
- **具名寄存器** **`a-z`** 是你可以显式使用、随意复制和剪切文本的寄存器
- **yank 寄存器** **`0`** 存储你上一次复制（yank）的内容
- **剪切寄存器** **`1-9`** 存储你通过删除或修改命令剪切的最近 9 项内容

例如，**`"ayas`** 会复制一个句子并将其存入寄存器 **`a`**。如果你想把它粘贴到别处，可以输入 **`"ap`**。另外，使用寄存器的大写版本（即用 **`A`** 代替 **`a`**）可以将你复制或剪切的内容追加到该寄存器中。

**yank 寄存器**让你可以访问通过 **`y`** 命令最后复制的内容。这很有用，因为删除和修改不会像覆盖无名寄存器那样覆盖这个寄存器。

**剪切寄存器**让你可以访问最近 9 项被删除或修改的内容。如果你想恢复之前删除的某些文本，这会非常有用。

任何时候，你都可以使用 `:reg` 命令查看寄存器中的内容。或者输入 `:reg {寄存器}` 查看特定寄存器的内容。

**在插入模式下**，使用 `CTRL-R {寄存器}` 可以将寄存器的内容粘贴到光标之后：

- **`CTRL-R "`** 粘贴无名寄存器的内容
- **`CTRL-R a`** 粘贴寄存器 **`a`** 的内容
- **`CTRL-R 0`** 粘贴 yank 寄存器的内容

## **命令行模式**

### **创建新文件**

一个常见的 Ex 命令是 `:edit`。它让你通过输入以下内容来打开或创建文件：

`:edit {文件的相对路径}`

### **保存或关闭文件**

- 使用 **`:write`**（简写 **`:w`**）保存文件
- 使用 **`:quit`**（简写 **`:q`**）关闭文件

- 使用 **`:write!`**（简写 **`:w!`**）即使文件已经保存过或是只读的也能保存
- 使用 **`:quit!`**（简写 **`:q!`**）不保存直接关闭文件。
- 使用 **`:wq`** 保存并关闭文件

- 使用 **`:wall`**（简写 **`:wa`**）保存所有文件
- 使用 **`:qall`**（简写 **`:qa`**）关闭所有文件
- 使用 **`:wqall`**（简写 **`:wqa`**）保存并关闭所有文件
- 使用 **`:qall!`**（简写 **`:qa!`**）不保存直接关闭所有文件

### **一次删除多行**

这些文本编辑 Ex 命令的形式如下：

**:[范围]命令[选项]**

- 使用数字（例如 **`:10,12d`** 删除第 10、11 和 12 行）
- 使用偏移量（例如 **`:10,+2d`** 删除第 10、11 和 12 行）
- 使用 **`.`** 代表当前行（例如 **`:.,+2d`** 删除当前行及接下来两行）
- 使用 **`%`** 代表整个文件（例如 **`:%d`** 删除整个文件）
- 使用 **`0`** 代表文件开头（例如 **`:0,+10d`** 删除前 10 行）
- 使用 **`$`** 代表文件末尾（例如 **`:.,$d`** 从当前行删除到文件末尾）
- 如果你用*可视模式*选中一段文本，然后输入 **`:`**，命令行区域会预先填入如下内容：**`:'<,'>`**，这是一个代表当前可视选区的特殊范围。（例如 **`:'<,'>d`** 表示删除当前选中的文本）

就像你可以用点运算符重复*普通模式*命令一样，Ex 命令也有一个重复命令。输入 **`@:`** 会重复上一条 ex 命令，之后你可以用 **`@@`** 再次重复它。

`:substitute`。它允许你把任意文本替换成你选择的内容。该命令的形式是：

**:[范围]s/{模式}/{替换内容}/{标志}**

其中：

- **`range`** 定义了应用替换的范围
- **`pattern`** 是一个搜索模式，描述我们想要更改的文本。和 **`/{模式}`** 一样，它支持正则表达式。
- **`substitute`** 是我们想要替换成的文本
- **`flags`** 让我们设置配置替换行为的选项

如果我们想更改**当前行中的所有匹配项**，需要加上 **`g`** 标志，即 *global*（全局）标志。

如果我们想更改**整个文件中的所有匹配项**，只需用 `%` 将整个文件指定为范围。

除了 **`g`** 标志，我们还可以使用：

- **`i`** 进行不区分大小写的搜索
- **`c`** 对每一处替换进行确认

## **分屏与标签页**

### **分屏**

- 使用 **`:sp {文件的相对路径}`** 命令在水平**分屏**（**sp**lit）中打开文件。
- 使用 **`:vsp {文件的相对路径}`** 命令在垂直**分屏**（**v**ertical **sp**lit）中打开文件。
- **`<CTRL-W> S`** 打开水平分屏（助记：**W**indow 和 **S**plit）。
- **`<CTRL-W> V`** 打开垂直分屏（助记：**V**ertical）。

使用这些命令中的任何一个都会打开一个指向你当前正在编辑的同一文件的分屏。因此创建分屏后，你需要在 Mac 上输入 **`CMD-P`** 或在 Windows/Linux 上输入 **`CTRL-P`** 来在该分屏中打开一个新文件。

![Vim 窗口分屏](https://www.barbarianmeetscoding.com/images/vim-window-splitting.jpg)

你可以使用 **`CTRL-W`** + **`hjkl`** 在分屏之间移动。

### **标签页**

在 Visual Studio Code 中，你可以在一个分屏内打开多个标签页。操作方法如下：

- 使用 **`:tabnew {文件}`** 在新标签页中打开文件
- 使用 **`:tabn`**（**`:tabnext`**）跳到**下**一个标签页
- 使用 **`:tabp`**（**`:tabprevious`**）跳到**上**一个标签页
- 使用 **`:tabo`**（**`:tabonly`**）关闭所有其他标签页

## **Surrounding（环绕）**

Vim 的 *surround* 插件是一个便捷的插件，用于添加、删除或更改文本周围的符号，比如括号和引号。它让你无需手动输入就能快速添加或删除配对的括号或引号。此外，该插件还能轻松地在 HTML 或 XML 标签中添加或删除标签。

例如，当你需要在单词或句子周围添加双引号时，可以把光标移到该单词或句子上，输入命令 "s"，然后按下 " 键，即可将选中的文本包裹在双引号中。如果你想使用其他类型的引号或括号，只需把 " 替换成其他符号即可。

surround 插件的一些常见命令如下：

- ys{动作}surround：将指定的文本区域包裹在指定的括号或引号中
- ds{字符}：删除指定的字符（如括号或引号）并合并周围的文本
- cs{字符1}{字符2}：用字符2替换字符1并更新周围的文本
- S{字符1}{字符2}：将选中文本的字符1替换为字符2并更新周围的文本

## **自定义映射**

Vim 中的*自定义映射*相当于其他编辑器中的快捷键，但特别强调对 Vim 来说极其自然的按键旋律。

## **多光标**

如果你想**基于单词搜索添加多个光标**，需要：

1. 将光标移到代码中某个单词上。
2. 输入 **`<CMD-D>`**（Windows/Linux 上为 **`CTRL-D`**）或 **`gb`** 添加另一个光标。这会让 Vim 进入*可视模式*，并准备对你选中的单词进行操作。
3. 继续输入 **`<CMD-D>`**（Windows/Linux 上为 **`CTRL-D`**）或 **`gb`** 添加更多光标，直到你完成。
4. 现在你可以在*可视模式*下执行操作（删除、修改等），或者
5. 用 **`<ESC>`** 回到*普通模式*，保留多光标并输入任何*普通模式*命令。

下面是添加多个光标的另一种方式：
1. 输入 **`<CMD-V>`** 进入可视模式；
2. 用 **`j/k`** 选择行；
3. （可选）输入 **`$`** 跳到行尾；
4. 输入 **`I/A`** 开始编辑行；
