# Vim

## **이동**

**hjkl**은 Vim의 핵심이자 가장 기본적인 모션입니다. 이를 통해 커서를 모든 방향으로 한 칸씩 이동할 수 있습니다.

![hjkl로 Vim에서 이동하기](https://www.barbarianmeetscoding.com/images/vim-basics-hjkl.jpg)

## **모드 전환**

**ESC/ 'Ctrl-[' / 'Ctrl-Z'** 와 **i/a** 를 사용하여 **일반 모드**와 **입력 모드** 사이를 전환합니다.

![일반 모드에서 입력 모드로, 다시 일반 모드로 돌아가기](https://www.barbarianmeetscoding.com/images/vim-basics-insert-to-normal.jpg)

## **기본 동작**

Vim에서 **Ctrl-C**는 복사 동작을 의미하지 않으며, Vim에서 사용하는 것처럼 **y(yank)** 를 사용합니다.

또한 **Ctrl-V** 와 동일한 작업을 수행하기 위해 **p(put)** 를 사용합니다.

- **`b`** (**b**ack)를 사용하여 단어의 시작으로 뒤로 이동합니다
- **`e`** (**e**nd)를 사용하여 단어의 끝으로 이동합니다
- **`ge`** 를 사용하여 단어의 끝으로 뒤로 이동합니다

단어를 단어 단위로 이동하려면 앞서 설명한 모션의 대문자 버전(**`W`**, **`B`**, **`E`**, **`gE`**)을 사용할 수 있습니다.

- **`f{character}`** (**f**ind)를 사용하여 줄에서 문자가 다음에 나타나는 위치로 이동합니다. 예를 들어 **`f"`** 는 다음 큰따옴표 위치로 이동합니다.
- 목표가 커서 뒤에 있다면 **`F{character}`** 를 사용하여 문자가 이전에 나타난 위치를 찾을 수 있습니다
- **`t{character}`** 를 사용하여 문자가 다음에 나타나기 직전으로 커서를 이동합니다 (`t{character}`는 해당 문자까지(un**t**il) 커서를 이동한다고 생각하세요).
- 마찬가지로 **`T{character}`** 를 사용하여 `t{character}`와 동일한 작업을 뒤로 수행할 수 있습니다

**`f{character}`** 를 사용한 후 **`;`** 를 입력하여 해당 문자가 다음에 나타나는 위치로 이동하거나 **`,`** 를 입력하여 이전 위치로 이동할 수 있습니다. **`;` 와 `,` 는 마지막 문자 검색을 반복하는 명령으로 볼 수 있습니다**.

- **`0`**: **줄의 첫 번째 문자**로 이동합니다
- **`^`**: **줄의 첫 번째 비공백 문자**로 이동합니다
- **`$`**: **줄의 끝**으로 이동합니다
- **`g_`**: **줄 끝의 비공백 문자**로 이동합니다
- **`}`** 는 전체 단락을 **아래로** 이동합니다
- **`{`** 는 비슷하지만 **위로** 이동합니다
- **`CTRL-D`** 는 페이지를 스크롤하여 **반 페이지 아래로 이동**할 수 있습니다
- **`CTRL-U`** 는 마찬가지로 스크롤하여 **반 페이지 위로 이동**할 수 있습니다
- **`/{pattern}`** 을 사용하여 파일 내에서 **앞으로 검색**합니다
- **`?{pattern}`** 을 사용하여 **뒤로 검색**합니다

여기서 원한다면 편집을 수행한 후 **`n`** 을 사용하여 다음 일치 항목으로 이동할 수 있습니다 (또는 **`N`** 으로 이전 항목으로). **`n` 은 검색을 반복하는 것으로 생각할 수 있습니다**.

Vim은 시간을 절약해 주는 것을 좋아합니다. 언제든지 **`/<Enter>`** 또는 **`?<Enter>`** 를 입력하여 마지막 검색을 실행하세요 (앞으로 또는 뒤로). 또는 **\*** 를 사용하여 커서 아래의 단어를 검색하세요 (**`#`** 는 뒤로 동일하게 수행).

**카운트는 명령의 효과를 배수로 늘릴 수 있는 숫자입니다**. 다음과 같이 명령 앞에 카운트를 붙여 사용할 수 있습니다:

**{count}{command}**

예를 들어:

- **`2w`** 는 커서를 2단어 앞으로 이동합니다.
- **`5j`** 는 커서 위치를 5줄 아래로 변경합니다.
- **`3;`** 는 문자가 세 번째로 나타나는 위치로 이동합니다.
- **`2/baby`** 는 문서에서 `baby`가 두 번째로 나타나는 위치로 이동합니다.

- **`gd`** 를 사용하여 커서 아래에 있는 것의 정의로 이동합니다.
- **`gf`** 를 사용하여 임포트의 파일로 이동합니다.
- **`gg`** 를 입력하여 파일의 맨 위로 이동합니다.
- **`{line}gg`** 를 사용하여 특정 줄로 이동합니다.
- **`G`** 를 사용하여 파일의 끝으로 이동합니다.
- **`%`** 를 입력하여 일치하는 **`({[]})`** 로 이동합니다.

## **연산자 시리즈**

다음 패턴 중 하나를 따라 연산자와 모션을 함께 사용하세요:

- {operator}{count}{motion}
- {count}{operator}{motion}

![Vim 연산자](https://www.barbarianmeetscoding.com/images/vim-operators.jpg)

- **연산자**는 수행하려는 동작을 결정합니다: 삭제, 변경, 복사, 포맷 등.
- **카운트**는 동작을 *카운트* 횟수만큼 수행하여 연산자의 효과를 배수로 늘립니다.
- **모션**은 연산자에 의해 정의된 동작을 적용할 텍스트 조각을 나타냅니다.

예를 들어 `d2w` 조합은 **두 단어를 삭제**할 수 있습니다.

![연산자 d2w 예시 - 두 단어 삭제](https://www.barbarianmeetscoding.com/images/vim-operators-d2w.jpg)

- **`d5j`** 를 사용하여 아래로 5줄을 삭제합니다
- **`df'`** 를 입력하여 현재 줄에서 커서부터 **`'`** 문자가 처음 나타나는 위치까지 모두 삭제합니다 (문자 자체 포함)
- 또는 **`dt'`** 를 입력하여 위 예시와 동일하지만 문자를 제외하고 삭제합니다 (즉 **`'`** 문자 직전까지)
- **`d/hello`** 를 사용하여 **`hello`** 가 처음 나타나는 위치까지 모두 삭제합니다
- **`ggdG`** 를 입력하여 문서 전체를 삭제합니다

## **유용한 연산자**

![유용한 Vim 연산자](https://www.barbarianmeetscoding.com/images/vim-operators-commands.jpg)

- **`c`** (**c**hange): change는 텍스트 조각을 삭제한 후 *입력 모드*로 전환하여 원래 텍스트를 다른 것으로 변경하면서 계속 입력할 수 있습니다. change 연산자는 **`d`** 와 **`i`** 명령이 하나로 결합된 것과 같습니다. 이 이중성 덕분에 가장 유용한 연산자입니다
- **`y`** (**y**ank): Vim 용어로 복사
- **`p`** (**p**ut): Vim 용어로 붙여넣기
- **`g~`** (대소문자 전환): 문자를 소문자에서 대문자로, 또는 그 반대로 변경합니다. 또는 **`gu`** 를 사용하여 소문자로, **`gU`** 를 사용하여 대문자로 만들 수 있습니다
- **`>`** (오른쪽 시프트): 들여쓰기를 추가합니다
- **`<`** (왼쪽 시프트): 들여쓰기를 제거합니다
- **`=`** (코드 포맷): 코드를 포맷합니다
- **연산자를 두 번 입력하면 전체 줄에 작동합니다**: **`dd`** 는 전체 줄을 삭제하고, **`cc`** 는 전체 줄을 변경합니다
- **연산자를 대문자로 입력하면 기본 동작의 더 강력한 (또는 대체) 버전을 수행합니다**: **`D`** 는 커서부터 줄 끝까지 삭제하고, **`C`** 는 줄 끝까지 변경하며, **`Y`** 는 **`yy`** 처럼 전체 줄을 복사하고, **`P`** 는 커서 앞에 붙여넣습니다

## **텍스트 오브젝트**

명령 내에서 텍스트 오브젝트를 지정하는 방법은 문자 **`a`** (텍스트 오브젝트 + 공백) 또는 **`i`** (공백 없는 **내부** 오브젝트)를 텍스트 오브젝트 자체를 나타내는 문자와 결합하는 것입니다:

![Vim 텍스트 오브젝트](https://www.barbarianmeetscoding.com/images/vim-text-objects.jpg)

내장 텍스트 오브젝트는 다음과 같습니다:

![Vim 텍스트 오브젝트 명령](https://www.barbarianmeetscoding.com/images/vim-text-objects-commands.jpg)

- **`w`** 는 **w**ord(단어)
- **`s`** 는 **s**entence(문장)
- **`'`**, **`"`**, **```** 는 따옴표
- **`p`** 는 **p**aragraph(단락)
- **`b`** (또는 **`(`**, **`)`**) 는 **`()`** 로 둘러싸인 블록
- **`B`** (또는 **`{`**, **`}`**) 는 **`{}`** 로 둘러싸인 블록
- **`<`**, **`>`** 는 **`<>`** 로 둘러싸인 블록
- **`[`**, **`]`** 는 **`[]`** 로 둘러싸인 블록
- **`t`** 는 태그

따라서 다양한 텍스트 조각을 삭제하려면 다음 명령 중 하나를 사용할 수 있습니다:

- **`daw`** 는 **단어**를 **삭제**합니다 (뒤따르는 공백 포함)
- **`ciw`** 는 **내부 단어**를 **변경**합니다
- **`das`** 는 **문장**을 **삭제**합니다 (**`dis`** 는 내부 문장을 삭제합니다)
- **`da"`** 는 큰따옴표 안의 내용을 따옴표 자체를 포함하여 삭제합니다 (**`di"`** 는 따옴표 **안**의 내용만 삭제하고 따옴표는 남깁니다)
- **`ci"`** 는 큰따옴표 안의 내용을 변경합니다
- **`dap`** 는 단락을 삭제합니다
- **`dab`** **`da(`** 또는 **`da)`** 는 **`(`** 로 둘러싸인 블록을 삭제합니다
- **`daB`** **`da{`** 또는 **`da}`** 는 **`{`** 로 둘러싸인 블록을 삭제합니다
- **`dat`** 는 HTML 태그를 삭제합니다
- **`cit`** 는 HTML 태그의 내용을 변경합니다

**텍스트 오브젝트를 연산자와 결합하는 것은 매우 강력하며** 자주 의존하게 될 것입니다. `cit`, `ci"`, `cib` 같은 것들은 정말 훌륭합니다.

**`.` 명령은 마지막 변경을 반복할 수 있게 해줍니다**.

- **`x`** 는 **`dl`** 과 동일하며 커서 아래의 문자를 삭제합니다
- **`X`** 는 **`dh`** 와 동일하며 커서 앞의 문자를 삭제합니다
- **`s`** 는 **`ch`** 와 동일하며, 커서 아래의 문자를 삭제하고 *입력 모드*로 전환합니다
- **`~`** 는 단일 문자의 대소문자를 전환합니다

- **`u`** 를 입력하면 마지막 변경을 실행 취소합니다,
- **`CTRL-R`** 을 입력하면 다시 실행합니다,

## **입력 모드**

- **`i`** 는 **i**nsert(삽입),
- **`a`** 는 **a**ppend(추가)입니다.
- **`I`** 는 현재 줄의 시작에서 *입력 모드*로 전환하고,
- **`A`** 는 끝에서 *입력 모드*로 전환합니다.

![입력 모드 명령](https://www.barbarianmeetscoding.com/images/vim-insert-mode.jpg)

1. **`o`** 는 현재 줄 아래에 새 줄을 삽입하고 입력 모드로 전환합니다 (약어: **o**pen a line below)
2. **`O`** 는 현재 줄 위에 새 줄을 삽입하고 입력 모드로 전환합니다
3. **`gi`** 는 마지막으로 변경한 위치에서 *입력 모드*로 전환합니다. 실수로 *입력 모드*에서 나왔을 때 원래 위치로 돌아가 계속 입력하고 싶을 때 유용합니다. (이 동작은 `gi`가 마지막으로 *입력 모드*를 떠난 위치로 이동하는 Vim과 약간 다릅니다).

![추가 입력 모드 명령](https://www.barbarianmeetscoding.com/images/vim-more-insert-mode.jpg)

- **`CTRL-h`** 는 입력한 **마지막 문자**를 삭제합니다
- **`CTRL-w`** 는 입력한 **마지막 단어**를 삭제합니다
- **`CTRL-u`** 는 입력한 **마지막 줄**을 삭제합니다

## **텍스트 선택과 비주얼 모드**

**비주얼 모드는 마우스로 텍스트를 선택하는 것과 동일한 Vim 기능입니다**.

![비주얼 모드 명령](https://www.barbarianmeetscoding.com/images/vim-visual-mode-commands.jpg)

- **`v`** 는 **문자 단위** 비주얼 모드입니다. 이 모드에서는 문자별로 텍스트를 선택할 수 있습니다
- **`V`** 는 **줄 단위** 비주얼 모드입니다. 이 모드에서는 줄별로 텍스트를 선택할 수 있습니다
- **`<C-V>`** 는 **블록 단위** 비주얼 모드입니다. 이 모드에서는 사각형 블록으로 텍스트를 선택할 수 있습니다

## **검색에 대한 작업**

**`gn`** 은 다음과 같이 작동합니다:

1. 검색 일치 항목 위에 있으면 *비주얼 모드*에서 해당 일치 항목을 선택합니다.
2. *비주얼 모드*에 있으면 현재 선택을 다음 일치 항목의 끝까지 확장합니다.
3. (그리고 가장 좋은 부분) *연산자 대기 모드*에 있으면 **다음 일치 항목에 대해 작업합니다**.

이게 무슨 의미일까요? **`gn` 을 활용하면 단 한 번의 키 입력으로 다음 일치 항목에 대해 작업할 수 있다는 뜻입니다**. **`gn`** 과 함께 **`.`** 명령은 **"이 변경을 다음 일치 항목에 적용"** 이라는 의미를 담게 됩니다

## **복사와 붙여넣기**

![Vim 복사 붙여넣기 명령](https://www.barbarianmeetscoding.com/images/vim-copy-paste-commands.jpg)

### **yank**

**`y`** 는 연산자입니다. 배운 모든 모션과 텍스트 오브젝트와 결합하여 원하는 대로 복사할 수 있습니다:

- **`yl`** 은 **글자**를 **복사**합니다,
- **`yaw`** 는 **단어**를 **복사**합니다,
- **`yas`** 는 **문장**을 **복사**합니다
- **`yi(`** 는 **`(`** 안의 모든 것을 **복사**합니다

**`yy`** 처럼 **`y`** 를 두 번 입력하면 **`dd`** 와 **`cc`** 처럼 **줄 단위 연산자**가 되어 전체 줄을 복사합니다. **`Y`** 명령도 전체 줄을 복사합니다. 저는 **`yy`** 를 선호하지만 원하는 것을 선택하세요.

### **paste**

붙여넣기를 하려면 **`p`** 명령과 그 변형을 사용합니다:

- **`p`** 는 커서 뒤에 붙여넣습니다
- **`P`** 는 커서 앞에 붙여넣습니다
- **`gp`** 는 **`p`** 와 동일하지만 붙여넣은 선택 영역 뒤에 커서를 놓습니다
- **`gP`** 는 **`P`** 와 동일하며 붙여넣은 선택 영역 뒤에 커서를 놓습니다

정말 놀라운 수준의 붙여넣기 유연성입니다.

Vim에서 붙여넣기는 약간 특별하며 **`p`** 와 **`P`** 의 동작은 문자를 복사했는지 줄을 복사했는지에 따라 달라집니다. **문자**를 복사했다면 붙여넣기는 해당 문자를 커서 뒤나 앞에 놓습니다 (별다를 것 없습니다). 그러나 **줄**을 복사했다면 붙여넣기는 커서가 있는 줄의 아래나 위에 해당 줄을 놓습니다.

![Vim 유용한 복사 붙여넣기](https://www.barbarianmeetscoding.com/images/vim-useful-copy-pasting.jpg)

### **레지스터**

*10분 전쯤의 `d` 와 `c` 를 기억하시나요?* 제가 그것들이 텍스트를 허무 속으로 삭제한다고 말했을 때 **거짓말을 했습니다!** 실제로는 **잘라내기**를 하는 것입니다.

레지스터는 여러 가지를 동시에 저장할 수 있는 특별한 클립보드와 같습니다. 다음 레지스터는 매우 유용합니다:

- **이름 없는 레지스터** **`"`** 는 레지스터를 명시적으로 지정하지 않았을 때 복사하거나 잘라낸 것이 저장되는 곳입니다. 기본 레지스터라고 할 수 있습니다.
- **이름 있는 레지스터** **`a-z`** 는 원하는 대로 텍스트를 복사하거나 잘라낼 때 명시적으로 사용할 수 있는 레지스터입니다
- **yank 레지스터** **`0`** 은 마지막으로 복사한 것을 저장합니다
- **cut 레지스터** **`1-9`** 는 delete 또는 change 명령으로 잘라낸 마지막 9개를 저장합니다

예를 들어 **`"ayas`** 는 문장을 복사하여 레지스터 **`a`** 에 저장합니다. 다른 곳에 붙여넣으려면 **`"ap`** 를 입력하면 됩니다. 또는 레지스터의 대문자 버전(즉 **`a`** 대신 **`A`**)을 사용하면 복사하거나 잘라낸 것을 해당 레지스터에 추가합니다.

**yank 레지스터**를 사용하면 **`y`** 명령으로 마지막으로 복사한 것에 접근할 수 있습니다. delete와 change가 이름 없는 레지스터를 덮어쓰는 것과 달리 이 레지스터는 덮어쓰지 않기 때문에 유용합니다.

**cut 레지스터**를 사용하면 마지막으로 삭제하거나 변경한 9개에 접근할 수 있습니다. 이전에 삭제한 텍스트를 복구하고 싶을 때 유용합니다.

언제든지 `:reg` 명령을 사용하여 레지스터의 내용을 확인할 수 있습니다. 또는 `:reg {register}` 를 입력하여 특정 레지스터의 내용을 검사할 수 있습니다.

**입력 모드에서** `CTRL-R {register}` 를 사용하면 커서 뒤에 레지스터의 내용을 붙여넣을 수 있습니다:

- **`CTRL-R "`** 는 이름 없는 레지스터의 내용을 붙여넣습니다
- **`CTRL-R a`** 는 레지스터 **`a`** 의 내용을 붙여넣습니다
- **`CTRL-R 0`** 는 yank 레지스터의 내용을 붙여넣습니다

## **명령줄 모드**

### **새 파일 만들기**

일반적인 Ex 명령은 `:edit` 입니다. 다음과 같이 입력하여 파일을 열거나 만들 수 있습니다:

`:edit {relative-path-to-file}`

### **파일 저장 또는 닫기**

- **`:write`** (약어 **`:w`**)를 사용하여 파일을 저장합니다
- **`:quit`** (약어 **`:q`**)를 사용하여 파일을 닫습니다

- **`:write!`** (약어 **`:w!`**)를 사용하면 이미 저장되었거나 읽기 전용이더라도 파일을 저장합니다
- **`:quit!`** (약어 **`:q!`**)를 사용하여 저장하지 않고 파일을 닫습니다.
- **`:wq`** 를 사용하여 파일을 저장하고 닫습니다

- **`:wall`** (약어 **`:wa`**)을 사용하여 모든 파일을 저장합니다
- **`:qall`** (약어 **`:qa`**)을 사용하여 모든 파일을 닫습니다
- **`:wqall`** (약어 **`:wqa`**)을 사용하여 모든 파일을 저장하고 닫습니다
- **`:qall!`** (약어 **`:qa!`**)를 사용하여 저장하지 않고 모든 파일을 닫습니다

### **한 번에 여러 줄 삭제하기**

이러한 텍스트 편집 Ex 명령은 다음 형태를 따릅니다:

**:[range]command[options]**

- 숫자 사용 (예: **`:10,12d`** 는 10, 11, 12줄을 삭제합니다)
- 오프셋 사용 (예: **`:10,+2d`** 는 10, 11, 12줄을 삭제합니다)
- **`.`** 로 표현되는 현재 줄 사용 (예: **`:.,+2d`** 는 현재 줄과 다음 두 줄을 삭제합니다)
- **`%`** 로 전체 파일 표현 (예: **`:%d`** 는 전체 파일을 삭제합니다)
- **`0`** 으로 파일의 시작 표현 (예: **`:0,+10d`** 는 처음 10줄을 삭제합니다)
- **`$`** 로 파일의 끝 표현 (예: **`:.,$d`** 는 현재 줄부터 파일 끝까지 삭제합니다)
- *비주얼 모드*로 텍스트를 선택한 후 **`:`** 를 입력하면 명령줄 영역에 다음과 같은 의미不明한 문자열이 미리 채워집니다: **`:'<,'>`** 이는 현재 비주얼 텍스트 선택을 나타내는 특별한 범위입니다. (예: **`:'<,'>d`** 는 현재 텍스트 선택을 삭제한다는 의미입니다)

일반 모드 명령을 점 연산자로 반복할 수 있는 것처럼, Ex 명령에도 반복 명령이 있습니다. **`@:`** 를 입력하면 마지막 ex 명령을 반복하고, 그 이후로는 **`@@`** 로 다시 반복할 수 있습니다.

`:substitute`. 원하는 텍스트 조각을 다른 것으로 대체할 수 있습니다. 이 명령의 형태는:

**:[range]s/{pattern}/{substitute}/{flags}**

여기서:

- **`range`** 는 대체를 적용할 범위를 정의합니다
- **`pattern`** 은 변경하려는 텍스트를 설명하는 검색 패턴입니다. **`/{pattern}`** 처럼 정규 표현식을 지원합니다.
- **`substitute`** 는 대체할 텍스트입니다
- **`flags`** 는 대체를 구성하는 옵션을 설정합니다

**현재 줄의 모든 항목**을 변경하려면 **`g`** 플래그 또는 *전역* 플래그를 추가해야 합니다.

**전체 파일의 모든 항목**을 변경하려면 `%` 로 전체 파일을 범위로 지정하면 됩니다.

**`g`** 플래그 외에도 사용할 수 있는 것:

- **`i`** 는 대소문자 구분 없는 검색
- **`c`** 는 각 대체를 확인

## **분할과 탭**

### **split**

- **`:sp {relative-path-to-file}`** 명령을 사용하여 수평 **sp**lit으로 파일을 엽니다.
- **`:vsp {relative-path-to-file}`** 명령을 사용하여 **v**ertical **sp**lit으로 파일을 엽니다.
- **`<CTRL-W> S`** 는 수평 분할을 엽니다 (약어: **W**indow와 **S**plit).
- **`<CTRL-W> V`** 는 수직 분할을 엽니다 (약어: **V**ertical).

이 명령 중 하나를 사용하면 현재 편집 중인 동일한 파일에 대한 분할이 열립니다. 따라서 분할을 생성한 후 Mac에서는 **`CMD-P`**, Windows/Linux에서는 **`CTRL-P`** 를 입력하여 해당 분할에서 새 파일을 엽니다.

![Vim에서 창 분할](https://www.barbarianmeetscoding.com/images/vim-window-splitting.jpg)

**`CTRL-W`** + **`hjkl`** 을 사용하여 분할 간에 이동할 수 있습니다.

### **tab**

Visual Studio Code에서는 분할 내에서 여러 탭을 열 수 있습니다. 그렇게 하려면:

- **`:tabnew {file}`** 을 사용하여 새 탭에서 파일을 엽니다
- **`:tabn`** (**`:tabnext`**)을 사용하여 **n**ext 탭으로 이동합니다
- **`:tabp`** (**`:tabprevious`**)를 사용하여 **p**revious 탭으로 이동합니다
- **`:tabo`** (**`:tabonly`**)를 사용하여 다른 모든 탭을 닫습니다

## **둘러싸기**

Vim의 *surround* 플러그인은 괄호나 따옴표처럼 텍스트를 둘러싸는 기호를 추가, 제거, 변경하는 데 유용한 플러그인입니다. 수동으로 입력하지 않고도 일치하는 괄호나 따옴표를 빠르게 추가하거나 제거할 수 있습니다. 또한 HTML이나 XML 태그 내에 태그를 쉽게 추가하거나 제거할 수 있습니다.

예를 들어, 단어나 문장 주위에 큰따옴표를 추가해야 할 때 커서를 단어나 문장으로 이동하고 "s" 명령 뒤에 " 키를 입력하여 선택한 텍스트를 큰따옴표로 감쌀 수 있습니다. 다른 종류의 따옴표나 괄호를 사용하려면 " 를 다른 기호로 바꾸면 됩니다.

surround 플러그인의 일반적인 명령은 다음과 같습니다:

- ys{motion}surround: 지정된 텍스트 영역을 지정된 괄호나 따옴표로 감쌉니다
- ds{char}: 지정된 문자(예: 괄호나 따옴표)를 제거하고 주변 텍스트를 병합합니다
- cs{char1}{char2}: char1을 char2로 바꾸고 주변 텍스트를 업데이트합니다
- S{char1}{char2}: 선택한 텍스트의 char1을 char2로 바꾸고 주변 텍스트를 업데이트합니다

## **사용자 정의 매핑**

Vim의 *사용자 정의 매핑*은 다른 편집기의 단축키와 동일하지만 Vim에 자연스러운 키 멜로디에 중점을 둡니다.

## **다중 커서**

**단어 검색을 기반으로 다중 커서를 추가**하려면:

1. 코드의 단어 위로 커서를 이동합니다.
2. **`<CMD-D>`** (Windows/Linux에서는 **`CTRL-D`**) 또는 **`gb`** 를 입력하여 다른 커서를 추가합니다. 이렇게 하면 Vim이 *비주얼 모드*로 전환되어 선택한 단어에 대해 작업할 준비가 됩니다.
3. 완료될 때까지 **`<CMD-D>`** (Windows/Linux에서는 **`CTRL-D`**) 또는 **`gb`** 를 입력하여 커서를 계속 추가합니다.
4. 이제 *비주얼 모드*에서 동작(삭제, 변경 등)을 수행하거나,
5. **`<ESC>`** 로 *일반 모드*로 돌아가 다중 커서를 유지한 채 *일반 모드* 명령을 입력합니다.

다중 커서를 추가하는 또 다른 방법:
1. **`<CMD-V>`** 를 입력하여 비주얼 모드로 전환;
2. **`j/k`** 로 줄 선택;
3. (선택 사항) **`$`** 를 입력하여 줄 끝으로 이동;
4. **`I/A`** 를 입력하여 줄 편집 시작;
