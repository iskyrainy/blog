# Vim

## **移动**

**hjkl** 是 Vim 中最核心、最基础的光标移动方式。它们让你可以向各个方向移动一个字符的位置。

![使用 hjkl 在 Vim 中移动](https://www.barbarianmeetscoding.com/images/vim-basics-hjkl.jpg)

## **模式切换**

使用 **ESC / 'Ctrl-[' / 'Ctrl-Z'** 和 **i/a** 在**普通模式**与**插入模式**之间切换。

![从普通模式切换到插入模式再切回](https://www.barbarianmeetscoding.com/images/vim-basics-insert-to-normal.jpg)

## **基本操作**

在 Vim 中，**Ctrl-C** 并不表示复制，而是像在 Vim 中那样使用 **y（代表 yank）**。

同样，我们用 **p（代表 paste）** 来完成与 **Ctrl-V** 相同的工作。

- 使用 **`b`**（**b**ack）向后跳到单词的开头
- 使用 **`e`**（**e**nd）跳到单词的末尾
- 使用 **`ge`** 向后跳到单词的末尾

如果你想按 WORD 逐词移动，可以使用之前描述动作的大写版本（**`W`**、**`B`**、**`E`**、**`gE`**）。

- 使用 **`f{character}`**（**f**ind）移动到当前行中某字符的下一次出现位置。例如，**`f"`** 会把你带到下一个双引号处。
- 如果目标在光标之前，可以使用 **`F{character}`** 查找某字符的上一次出现位置
- 使用 **`t{character}`** 将光标移动到某字符下一次出现位置之前（可以把 `t{character}` 理解为让光标移动 un**t**il 该字符）。
- 同样，可以用 **`T{character}`** 做与 `t{character}` 相同的事，但方向相反

使用 **`f{character}`** 之后，可以输入 **`;`** 跳到该字符的下一次出现位置，或输入 **`,`** 跳到上一次出现位置。**你可以把 `;` 和 `,` 看作重复上一次字符搜索的命令**。

- **`0`**：移动到**行的第一个字符**
- **`^`**：移动到**行的第一个非空白字符**
- **`$`**：移动到**行尾**
- **`g_`**：移动到**行尾的非空白字符**
- **`}`** 向下跳转整个段落
- **`{`** 类似，但方向向上
- **`CTRL-D`** 让你通过滚动页面**向下移动半页**
- **`CTRL-U`** 让你同样通过滚动**向上移动半页**
- 使用 **`/{pattern}`** 在文件中**向前搜索**
- 使用 **`?{pattern}`** **向后搜索**

在那里你可以根据需要做一些编辑，之后再使用 **`n`** 跳到下一个匹配项（或用 **`N`** 跳到上一个）。**你可以把 `n` 看作重复一次搜索**。

Vim 喜欢为你节省时间：随时输入 **`/<Enter>`** 或 **`?<Enter>`** 来运行上一次搜索（向前或向后）。或者使用 **\*** 搜索光标下的单词（**`#`** 做相同的事，但方向相反）。

**Counts 是数字，可以让你倍增命令的效果**。你可以像这样在任何命令前加上 count 来使用它们：

**{count}{command}**

例如：

- **`2w`** 让我们将光标向前移动 2 个单词。
- **`5j`** 将光标位置向下移动 5 行。
- **`3;`** 让你跳到某字符的第 3 次出现位置。
- **`2/baby`** 让你飞到文档中 `baby` 的第 2 次出现位置。

- 使用 **`gd`** 跳转到光标下任何内容的定义。
- 使用 **`gf`** 跳转到 import 中的文件。
- 输入 **`gg`** 跳到文件顶部。
- 使用 **`{line}gg`** 跳到指定行。
- 使用 **`G`** 跳到文件末尾。
- 输入 **`%`** 跳转到匹配的 **`({[]})`**。

## **一系列操作符**

通过遵循以下任意模式，将操作符和动作结合使用：

- {operator}{count}{motion}
- {count}{operator}{motion}

![Vim 操作符](https://www.barbarianmeetscoding.com/images/vim-operators.jpg)

- **操作符**决定你想执行的动作：删除、修改、复制、格式化等。
- **count**允许你通过执行 *count* 次动作来倍增操作符的效果。
- **动作**表示要应用操作符所定义动作的那段文本。

例如，`d2w` 组合允许你**删除两个单词**。

![一个操作符示例 d2w 删除两个单词](https://www.barbarianmeetscoding.com/images/vim-operators-d2w.jpg)

- 使用 **`d5j`** 向下删除 5 行
- 输入 **`df'`** 删除当前行中从光标到 **`'`** 字符第一次出现位置的所有内容（包括该字符本身）
- 或输入 **`dt'`** 做与上例类似的事，但不包括该字符（即直到或刚好在 **`'`** 字符之前）
- 使用 **`d/hello`** 删除直到 **`hello`** 第一次出现位置的所有内容
- 输入 **`ggdG`** 删除整个文档

## **实用操作符**

![一些实用的 Vim 操作符](https://www.barbarianmeetscoding.com/images/vim-operators-commands.jpg)

- **`c`**（**c**hange）：Change 会删除一段文本，然后让你进入*插入模式*，以便继续输入，将原始文本改成其他内容。change 操作符就像**`d`**和**`i`**命令合二为一。这种双重性使它成为最有用的操作符
- **`y`**（**y**ank）：在 Vim 术语中表示复制
- **`p`**（**p**ut）：在 Vim 术语中表示粘贴
- **`g~`**（切换大小写）：在大小写之间切换字母。或者使用 **`gu`** 将内容变为小写，使用 **`gU`** 将内容变为大写
- **`>`**（右移）：增加缩进
- **`<`**（左移）：移除缩进
- **`=`**（格式化代码）：格式化代码
- **将操作符重复两次以使其作用于整行**：**`dd`** 删除整行，**`cc`** 修改整行，等等。
- **将操作符大写以执行更强（或替代）版本的默认行为**：**`D`** 从光标删除到行尾，**`C`** 修改到行尾，**`Y`** 像 **`yy`** 一样复制整行，**`P`** 在光标前粘贴内容，等等。

## **文本对象**

在命令中指定文本对象的方式，是将字母 **`a`**（**a** text object，包含空白）或 **`i`**（**inner** object，不含空白）与表示文本对象本身的字符组合起来：

![Vim 文本对象](https://www.barbarianmeetscoding.com/images/vim-text-objects.jpg)

内置文本对象有：

![Vim 文本对象命令](https://www.barbarianmeetscoding.com/images/vim-text-objects-commands.jpg)

- **`w`** 表示 **w**ord（单词）
- **`s`** 表示 **s**entence（句子）
- **`'`**、**`"`**、**```** 表示引号
- **`p`** 表示 **p**aragraph（段落）
- **`b`**（或 **`(`**、**`)`**）表示由 **`()`** 包围的块
- **`B`**（或 **`{`**、**`}`**）表示由 **`{}`** 包围的块
- **`<`**、**`>`** 表示由 **`<>`** 包围的块
- **`[`**、**`]`** 表示由 **`[]`** 包围的块
- **`t`** 表示 tag（标签）。

因此，为了删除不同的文本片段，你可以使用以下任意命令：

- **`daw`** **d**elete **a** **w**ord，即删除一个单词（包括尾随空白）
- **`ciw`** **c**hange **i**nner **w**ord，即修改内部单词
- **`das`** **d**elete **a** **s**entence，即删除一个句子（**`dis`** 删除内部句子）
- **`da"`** 删除双引号中的内容，包括引号本身（**`di"`** 只删除引号**i**nside 的内容，保留引号）
- **`ci"`** 修改双引号中的内容
- **`dap`** 删除一个段落
- **`dab`** **`da(`** 或 **`da)`** 删除由 **`(`** 包围的块
- **`daB`** **`da{`** 或 **`da}`** 删除由 **`{`** 包围的块
- **`dat`** 删除一个 HTML 标签
- **`cit`** 修改一个 HTML 标签的内容

**将文本对象与操作符结合使用极其强大**，你会发现自己非常频繁地依赖它们。像 `cit`、`ci"` 和 `cib` 这样的东西简直太棒了。

**`.` 命令允许你重复上一次所做的修改**。

- **`x`** 等价于 **`dl`**，删除光标下的字符
- **`X`** 等价于 **`dh`**，删除光标前的字符
- **`s`** 等价于 **`ch`**，删除光标下的字符并让你进入*插入模式*
- **`~`** 切换单个字符的大小写

- 输入 **`u`**，你将撤销上一次修改，
- 输入 **`CTRL-R`**，你将重做它，

## **插入模式**

- **`i`** 表示 **i**nsert，
- **`a`** 表示 **a**ppend。
- **`I`** 将你置于当前行开头的*插入模式*，而
- **`A`** 将你置于行尾的*插入模式*。

![插入模式命令](https://www.barbarianmeetscoding.com/images/vim-insert-mode.jpg)

1. **`o`** 在当前行下方插入一个新行，并让你进入插入模式（助记：**o**pen a line below）
2. **`O`** 在当前行上方插入一个新行，同样让你进入插入模式
3. **`gi`** 将你置于上次修改位置的*插入模式*。如果你不小心退出了*插入模式*，想回到刚才的位置继续输入，这会非常有用。（这种行为与 Vim 略有不同，在 Vim 中 `gi` 会把你送到上次离开*插入模式*的位置）。

![更多插入模式命令](https://www.barbarianmeetscoding.com/images/vim-more-insert-mode.jpg)

- **`CTRL-h`** 让你删除输入的**最后一个字符**
- **`CTRL-w`** 让你删除输入的**最后一个单词**
- **`CTRL-u`** 让你删除输入的**最后一行**

## **选择文本与可视模式**

**可视模式相当于 Vim 中用鼠标选择文本**。

![可视模式命令](https://www.barbarianmeetscoding.com/images/vim-visual-mode-commands.jpg)

- **`v`** 为**逐字符**可视模式。此模式让你逐个字符地选择文本
- **`V`** 为**逐行**可视模式。这个模式让你逐行选择文本
- **`<C-V>`** 为**逐块**可视模式。最后一个模式让你使用矩形块选择文本

## **对搜索进行操作**

**`gn`** 的工作方式如下：

1. 如果你位于某个搜索匹配项上，它会在*可视模式*下选中该匹配项。
2. 如果你处于*可视模式*，它会将当前选择扩展到下一个匹配项的末尾。
3. （最棒的部分）如果你处于*操作符待决模式*，**它会对下一个匹配项进行操作**。

这一切意味着什么？**这意味着利用 `gn`，我们可以仅用一次按键就对下一个匹配项进行操作**。借助 **`gn`**，**`.`** 命令包含了**“将此修改应用到下一个匹配项”**的含义。

## **复制与粘贴**

![Vim 复制粘贴命令](https://www.barbarianmeetscoding.com/images/vim-copy-paste-commands.jpg)

### **yank**

**`y`** 是一个操作符。你可以将它与你学过的任何动作和文本对象结合使用，随心所欲地复制内容：

- **`yl`** **y**ank 一个**l**etter（字母），
- **`yaw`** **y**ank 一个 **w**ord（单词），
- **`yas`** **y**ank 一个 **s**entence（句子）
- **`yi(`** **y**ank **`(`** 内的所有内容，依此类推……

如果你像 **`yy`** 那样重复 **`y`**，就会得到一个**逐行操作符**，就像 **`dd`** 和 **`cc`** 一样，复制整行。**`Y`** 命令也会复制完整的一行。我更倾向于使用 **`yy`**，但你可以随意选择自己喜欢的。

### **paste**

为了粘贴内容，你使用 **`p`** 命令及其变体：

- **`p`** 在光标后粘贴内容
- **`P`** 在光标前粘贴内容
- **`gp`** 与 **`p`** 相同，但将光标放在粘贴内容之后
- **`gP`** 与 **`P`** 相同，并将光标放在粘贴内容之后

这真是令人惊叹的粘贴灵活性。

在 Vim 中粘贴有些特别，**`p`** 和 **`P`** 的行为取决于你复制的是字符还是行。如果你复制的是**字符**，那么粘贴会将这些字符放在光标之后或之前（这没有什么意外）。然而，如果你复制的是**行**，那么粘贴会将这些行放在光标所在行的下方或上方。

![Vim 实用的复制粘贴](https://www.barbarianmeetscoding.com/images/vim-useful-copy-pasting.jpg)

### **register**

*你还记得大約 10 分钟前的 `d` 和 `c` 吗？* 好吧，当我说它们把文本删除到虚无时，**我撒谎了！** 它们实际上是**剪切**了内容。

寄存器就像一个特殊的剪贴板，你可以在其中同时保存多个内容。以下寄存器非常有用：

- **匿名寄存器** **`"`** 是当你没有显式指定寄存器时，复制和剪切内容存放的地方。可以说是默认寄存器。
- **命名寄存器** **`a-z`** 是你可以显式使用的寄存器，用于随意复制和剪切文本
- **yank 寄存器** **`0`** 存储你最后一次 yank（复制）的内容
- **剪切寄存器** **`1-9`** 存储你通过 delete 或 change 命令剪切的上 9 个内容

例如，**`"ayas`** 会复制一个句子并将其存储到寄存器 **`a`** 中。现在如果你想把它粘贴到其他地方，可以输入 **`"ap`**。或者，使用寄存器的大写版本（即用 **`A`** 代替 **`a`**）会将你复制或剪切的内容追加到该寄存器中。

**yank 寄存器**让你可以访问通过 **`y`** 命令最后复制的内容。这很有帮助，因为 delete 和 change 不会像覆盖匿名寄存器那样覆盖这个寄存器。

**剪切寄存器**让你可以访问你最后删除或修改的 9 个内容。如果你之前删除了一些文本并想恢复它，这会非常有用。

在任何时候，你都可以使用 `:reg` 命令查看寄存器中的内容。或者输入 `:reg {register}` 查看特定寄存器的内容。

**在插入模式下**，使用 `CTRL-R {register}` 可以在光标后粘贴寄存器的内容：

- **`CTRL-R "`** 粘贴匿名寄存器的内容
- **`CTRL-R a`** 粘贴寄存器 **`a`** 的内容
- **`CTRL-R 0`** 粘贴 yank 寄存器的内容

## **命令行模式**

### **创建新文件**

一个常见的 Ex 命令是 `:edit`。它让你通过输入以下内容来打开或创建文件：

`:edit {relative-path-to-file}`

### **保存或关闭文件**

- 使用 **`:write`**（简写 **`:w`**）保存文件
- 使用 **`:quit`**（简写 **`:q`**）关闭文件

- 使用 **`:write!`**（简写 **`:w!`**）即使文件已经保存过或为只读，也强制保存文件
- 使用 **`:quit!`**（简写 **`:q!`**）不保存就关闭文件。
- 使用 **`:wq`** 保存并关闭文件

- 使用 **`:wall`**（简写 **`:wa`**）保存所有文件
- 使用 **`:qall`**（简写 **`:qa`**）关闭所有文件
- 使用 **`:wqall`**（简写 **`:wqa`**）保存并关闭所有文件
- 使用 **`:qall!`**（简写 **`:qa!`**）不保存就关闭所有文件

### **一次性删除多行**

这些文本编辑 Ex 命令采用以下形式：

**:[range]command[options]**

- 使用数字（例如 **`:10,12d`** 删除第 10、11 和 12 行）
- 使用偏移量（例如 **`:10,+2d`** 删除第 10、11 和 12 行）
- 使用由 **`.`** 表示的当前行（例如 **`:.,+2d`** 删除当前行及后两行）
- 使用 **`%`** 表示整个文件（例如 **`:%d`** 删除整个文件）
- 使用 **`0`** 表示文件开头（例如 **`:0,+10d`** 删除前 10 行）
- 使用 **`$`** 表示文件末尾（例如 **`:.,$d`** 从当前行删除到文件末尾）
- 如果你使用*可视模式*进行文本选择，然后输入 **`:`**，你的命令行区域会预填充以下乱码：**`:'<,'>`**，这是一个表示当前可视文本选择的特殊范围。（例如 **`:'<,'>d`** 表示删除当前文本选择）

就像你可以用点操作符重复*普通模式*命令一样，Ex 命令也有一个重复命令。输入 **`@:`** 就会重复上一条 ex 命令，此后你可以用 **`@@`** 再次重复它。

 `:substitute`。它允许你将任意的文本片段替换为你选择的其他内容。此命令的形式为：

**:[range]s/{pattern}/{substitute}/{flags}**

其中：

- **`range`** 定义我们将应用替换的范围
- **`pattern`** 是描述我们想要修改的文本的搜索模式。像 **`/{pattern}`** 一样，它支持正则表达式。
- **`substitute`** 是我们想要替换成的文本
- **`flags`** 让我们设置配置替换的选项

如果我们想修改**当前行中的所有出现位置**，那么需要添加 **`g`** 标志，即 *global* 标志。

如果我们想修改**整个文件中的所有出现位置**，只需用 `%` 将整个文件指定为范围。

除了 **`g`** 标志外，我们还可以使用：

- **`i`** 进行不区分大小写的搜索
- **`c`** 确认每一次替换

## **分屏与标签页**

### **split**

- 使用 **`:sp {relative-path-to-file}`** 命令在水平**sp**lit（分屏）中打开文件。
- 使用 **`:vsp {relative-path-to-file}`** 命令在**v**ertical **sp**lit（垂直分屏）中打开文件。
- **`<CTRL-W> S`** 打开水平分屏（助记：**W**indow 和 **S**plit）。
- **`<CTRL-W> V`** 打开垂直分屏（助记：**V**ertical）。

使用这些命令中的任意一个都会打开一个指向你当前正在编辑的同一文件的分屏。因此创建分屏后，你需要在 Mac 上输入 **`CMD-P`** 或在 Windows/Linux 上输入 **`CTRL-P`**，才能在该分屏中打开新文件。

![Vim 中的窗口分屏](https://www.barbarianmeetscoding.com/images/vim-window-splitting.jpg)

你可以使用 **`CTRL-W`** + **`hjkl`** 在分屏之间移动。

### **tab**

在 Visual Studio Code 中，你可以在一个分屏内打开多个标签页。为此：

- 使用 **`:tabnew {file}`** 在新标签页中打开文件
- 使用 **`:tabn`**（**`:tabnext`**）转到**n**ext（下一个）标签页
- 使用 **`:tabp`**（**`:tabprevious`**）转到 **p**revious（上一个）标签页
- 使用 **`:tabo`**（**`:tabonly`**）关闭所有其他标签页

## **Surrounding**

Vim 的 *surround* 插件是一个方便的插件，用于添加、删除或修改文本周围的符号，例如括号和引号。它让你无需手动输入，就能快速添加或删除匹配的括号或引号。此外，该插件还能轻松添加或删除 HTML 或 XML 标签中的标签。

例如，当你需要在一个单词或句子周围添加双引号时，可以将光标移到该单词或句子上，输入命令 "s"，然后按 " 键，即可将选中的文本包裹在双引号中。如果你想使用其他类型的引号或括号，只需将 " 替换为其他符号即可。

surround 插件的一些常用命令如下：

- ys{motion}surround：将指定文本区域包裹在指定的括号或引号中
- ds{char}：删除指定字符（如括号或引号）并合并周围的文本
- cs{char1}{char2}：将 char1 替换为 char2 并更新周围的文本
- S{char1}{char2}：将选中文本的 char1 替换为 char2 并更新周围的文本

## **自定义映射**

Vim 中的*自定义映射*相当于其他编辑器中的快捷键，但特别强调对 Vim 来说非常自然的按键旋律。

## **多光标**

如果你想**基于单词搜索添加多个光标**，需要：

1. 将光标移到代码中某个单词上。
2. 输入 **`<CMD-D>`**（Windows/Linux 上为 **`CTRL-D`**）或 **`gb`** 添加另一个光标。这会让 Vim 进入*可视模式*，并准备好对你已选中的单词进行操作。
3. 输入 **`<CMD-D>`**（Windows/Linux 上为 **`CTRL-D`**）或 **`gb`** 继续添加光标，直到完成为止。
4. 现在你可以在*可视模式*下执行一个动作（删除、修改等），或者
5. 用 **`<ESC>`** 回到*普通模式*，并在保留多光标的情况下输入任意*普通模式*命令。

这里是另一种添加多个光标的方法：
1. 输入 **`<CMD-V>`** 进入可视模式；
2. 用 **`j/k`** 选择行；
3. （可选）输入 **`$`** 跳到行尾；
4. 输入 **`I/A`** 开始编辑行；
